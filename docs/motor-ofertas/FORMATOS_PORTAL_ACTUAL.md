# Formatos actuales del portal de ofertas

Fecha de resguardo: 2026-07-25.

Este documento conserva la referencia visual y de navegacion vigente antes de
reconstruir el portal sobre una base comercial unica. No define precios,
ofertas, reglas ni vigencias.

## Formato principal visible

Cabecera roja Claro con el titulo de la familia comercial y menu horizontal.
El formato de Fijo muestra filtros por familia debajo del menu, como por
ejemplo Telefonia Medida, Telefonia Ilimitada, 2Play, Television y
Complementos y Valores Agregados.

## Regla de migracion

La estructura visual puede conservarse como referencia. Los contenidos
comerciales se migraran desde documentos oficiales a datos versionados; no se
usaran estos archivos HTML o JavaScript como fuente comercial.
